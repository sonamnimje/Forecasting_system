# 📈 Sales Forecasting System
### End-to-End Time Series Forecasting with REST API

> **Assignment**: Data Science – Production-Ready Forecasting System  
> **Goal**: Forecast next 8 weeks of sales per state using 4 ML models + auto model selection

## 🤖 Models

### 1. ARIMA / SARIMA
- Auto-selects (p, d, q)(P, D, Q) order via AIC using `pmdarima.auto_arima`
- Handles trend and 52-week annual seasonality
- Falls back to ARIMA(1,1,1) if pmdarima unavailable

### 2. Facebook Prophet
- Yearly + monthly seasonality
- Built-in US holiday calendar
- Tunable changepoint and seasonality priors

### 3. XGBoost (Gradient Boosting)
- **Lag features**: t-1, t-2, t-4, t-8, t-13, t-26, t-52
- **Rolling stats**: mean, std, max, min over 4, 8, 13, 26-week windows
- **Calendar**: day-of-week, week-of-year, month, quarter, holiday flag
- Recursive multi-step prediction (no data leakage)

### 4. LSTM (Deep Learning)
- Stacked 2-layer LSTM with BatchNorm + Dropout
- 52-week lookback window
- Huber loss, Adam optimizer, early stopping
- Z-score normalisation per state
- Recursive multi-step forecasting

---

## 📊 Model Selection

Each model is evaluated on a **held-out validation set** (last 16 weeks of training data, no leakage). Selection criterion:

```
Best Model = argmin(SMAPE)
```

Metrics computed: **RMSE**, **MAE**, **MAPE**, **SMAPE**

## 🌐 REST API

Start the server:
```bash
uvicorn api.main:app --reload --port 8000
```

### Endpoints

| Method | Endpoint               | Description                                  |
|--------|------------------------|----------------------------------------------|
| GET    | `/`                    | Health check                                 |
| GET    | `/health`              | Data + results status                        |
| POST   | `/train`               | Start training (async background job)        |
| POST   | `/train/sync`          | Start training (synchronous, blocks)         |
| GET    | `/states`              | List all trained states                      |
| GET    | `/forecast/{state}`    | 8-week forecast for a specific state         |
| GET    | `/forecast`            | Forecasts for all (or filtered) states       |
| GET    | `/compare`             | Model comparison metrics (all states)        |
| GET    | `/best-models`         | Summary of winning models per state          |

### Example requests

```bash
# Train synchronously on default data
curl -X POST http://localhost:8000/train/sync \
  -H "Content-Type: application/json" \
  -d '{"horizon": 8, "val_weeks": 16}'

# Get 8-week forecast for California
curl http://localhost:8000/forecast/California

# Compare all models for Texas
curl "http://localhost:8000/compare?state=Texas"

# Get forecasts for multiple states
curl "http://localhost:8000/forecast?states=California,Texas,Florida"
```

## 🔑 Key Design Decisions

| Decision | Approach |
|---|---|
| Missing dates | Fill with weekly calendar, interpolate missing sales |
| Missing values | Linear interpolation → forward/back fill |
| Train/val split | Chronological – last 16 weeks held out (no leakage) |
| Model selection | SMAPE on validation set (robust to scale differences) |
| Final forecast | Best model re-trained on **full** data before predicting |
| API architecture | FastAPI + Pydantic v2 (async-ready, auto-docs) |

## 🧩 Extending the System

- **Add a model**: Create `models/my_model.py` with `fit()`, `predict()`, `predict_val()` methods and add it to the `models` dict in `model_selector.py`
- **Use real data**: Drop your CSV at `data/sales_data.csv` (columns: `date`, `state`, `sales`)
- **Change horizon**: Set `horizon` parameter in `/train/sync` request or `run_pipeline(horizon=12)`
- **Add a database**: Replace `results/*.csv` with SQLAlchemy inserts in `model_selector._save_results()`
