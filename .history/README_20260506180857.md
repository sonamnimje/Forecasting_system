# 📈 Sales Forecasting System

### End-to-End Multi-Model Sales Forecasting with FastAPI Deployment

> **Objective:** Forecast the next **8 weeks of sales for each state** using historical sales data and automatically select the best forecasting model.

---

# 🚀 Project Overview

This project is a production-ready forecasting pipeline that predicts future sales for multiple U.S. states using historical sales records.

The system:

✅ Uses a **real provided dataset** (`Sales_data.csv`)
✅ Cleans and preprocesses raw data
✅ Aggregates category-wise sales into state-level sales
✅ Handles missing values and invalid records
✅ Performs feature engineering
✅ Trains multiple forecasting models
✅ Compares model performance
✅ Automatically selects the best model
✅ Generates future forecasts
✅ Deploys predictions via FastAPI REST API

---
