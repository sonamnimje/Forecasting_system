# 📈 Sales Forecasting System

### End-to-End Time Series Forecasting with REST API

> **Assignment:** Data Science – Production-Ready Forecasting System
> **Goal:** Forecast the next **8 weeks of sales for each state** using multiple forecasting models with automatic model selection.

---

# 🚀 Project Overview

This project is a **production-ready sales forecasting system** that predicts future weekly sales for multiple states.

The system:

* Generates synthetic sales data (or accepts real data)
* Cleans missing values
* Engineers time-series features
* Trains **4 forecasting models**
* Evaluates all models on validation data
* Automatically selects the best model using **SMAPE**
* Generates future forecasts
* Exposes results via a **FastAPI REST API**

# Model Selection Logic

Each model is evaluated using:

* RMSE
* MAE
* MAPE
* SMAPE

Best model selection:

```python
Best Model = Lowest SMAPE
```

The best-performing model is retrained on full data before generating final forecasts.

# REST API Endpoints

| Method | Endpoint            | Purpose                 |
| ------ | ------------------- | ----------------------- |
| GET    | `/`                 | Root endpoint           |
| GET    | `/health`           | System health           |
| POST   | `/train`            | Async training          |
| POST   | `/train/sync`       | Synchronous training    |
| GET    | `/states`           | List all states         |
| GET    | `/forecast/{state}` | Forecast specific state |
| GET    | `/forecast`         | Forecast all states     |
| GET    | `/compare`          | Compare models          |
| GET    | `/best-models`      | Best models summary     |
